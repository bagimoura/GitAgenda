# 📅 GitAgenda

Agenda que conecta vida pessoal á projetos no GitHub.

# Objetivos
-> Planejar e acompanhar ciclos de Sprint; <br>
-> Integrar informações de repositórios GitHub; <br>
-> Visualizar commits e atividades de desenvolvimento no calendário. <br>

# Funcionalidades
-> Cadastro e visualização de atividades e compromissos - mensal, semanal e diária; <br>
-> Organização por categorias; <br>
-> Associação de atividades a repositórios GitHub; <br>
-> Criação e planejamento de Sprints; <br>
-> Associação de tarefas às Sprints; <br>
-> Conexão com a conta GitHub; <br>
-> Seleção de repositórios; <br>
-> Visualização de commits. <br>
