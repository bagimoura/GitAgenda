# 📅 GitAgenda

Agenda que conecta vida pessoal á projetos no GitHub.

# Objetivos
-> Planejar e acompanhar ciclos de Sprint; </b>
-> Integrar informações de repositórios GitHub;
-> Visualizar commits e atividades de desenvolvimento no calendário.

# Funcionalidades
-> Cadastro e visualização de atividades e compromissos - mensal, semanal e diária;
-> Organização por categorias;
-> Associação de atividades a repositórios GitHub;
-> Criação e planejamento de Sprints;
-> Associação de tarefas às Sprints;
-> Conexão com a conta GitHub;
-> Seleção de repositórios;
-> Visualização de commits.
